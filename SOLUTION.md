## Решения
к предстоящим отношу матчи со статусами scheduled и postponed, так как они еще не прошли
в завершенные входят матчи со статусом finished
оставшиеся live показываются в общем выводе, так как игра уже началась, но ещё не завершилась

если score равен null - "Счёт пока неизвестен"
Если startsAt равен null - "Дата не назначена"
Дата преобразуется через Date и toLocaleString('ru-RU') без указания часового пояса, используется часовой пояс устройства
для неизвестного статуса предусмотрено значение «Неизвестен»

## Баги из части 2
1. Звёздочки:
2 ошибки
1 - неправильная проверка избранного через Boolean(favorites.indexOf(id))
indexOf() возвращает 0 для первого элемента и -1 для отсутствующего, поэтому результат преобразования в boolean был неверным
заменила проверку на favorites.includes(id).
2 - изменение массива состояния напрямую через push() и splice()
после этого в setFavorites() передавался тот же массив, поэтому React мог не перерисовать компонент
исправила обновление состояния - при добавлении создаётся новый массив через spread-оператор, а при удалении через filter()
Подключила FavoriteButton к карточкам матчей через isFavorite() и toggle()

2. «Обновлено N сек назад»: использовалось setSeconds(seconds + 1), счётчик доходил до 1 и переставал увеличиваться.
также интервал не очищался, since не использовалось
исправление: количество секунд - разница между текущим временем (Date.now()) и временем последней успешной загрузки (since.getTime())
интервал обновляет значение каждую секунду и очищается через clearInterval, при изменении since эффект запускается заново
